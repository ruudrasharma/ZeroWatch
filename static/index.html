Alert queue

Every flow that was not passed as benign, highest priority first. Closing an alert as confirmed or as a false alarm also labels the flow for the next retrain.

Capture

Score real traffic. A .pcap file is rebuilt into connections, each connection becomes a flow in the data contract, and every source is also judged on all of its flows together.

No capture analyzed yetUse the sample capture, or choose a .pcap, .pcapng or Zeek conn.log file up to 5 MB. Record one with: tcpdump -w traffic.pcap -c 20000

Assets

Tell ZeroWatch what it is protecting. Each asset gets one passive exposure check (its HTTPS headers and TLS certificate). Alerts on the services it runs are then given a priority: the same attack ranks higher against an exposed asset.

contract service names, comma separated
Only public http/https hosts are scanned; internal addresses are refused.

Hunt

Possible zero-days from the log, grouped into campaigns. Each campaign gets a generated detection rule. Label a campaign, retrain, and the model learns it: a challenger is trained and replaces the live model only if it does better.

Batch scoring

Paste CSV with a header row, or choose a CSV file. Up to 500 flows per request; every row must satisfy the data contract.

Model

What is deployed, how it was chosen, and how it performs on traffic it has never seen.

Monitoring

Every scored flow is logged. Drift compares those logged inputs with the training data; a large shift means the model is being asked about traffic it was not trained on.
